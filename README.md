# JWT Demo - Spring Boot 3 & Security 6 (Nimbus JOSE + JWT)

> Bài tập môn Lập trình Web

---

## 📌 Nội dung đã làm

1. **Làm lại bài tập ví dụ JWT trong bài giảng**
   - Đăng ký / đăng nhập sinh JWT
   - Xác thực request bằng `Authorization: Bearer <token>`
   - Các API: `/auth/**`, `/users/**`
   - Giao diện login / profile render bằng AJAX

2. **Thay thư viện JWT (JJWT) bằng Nimbus JOSE + JWT**
   - Tạo, ký và xác thực token (HS256) bằng `com.nimbusds:nimbus-jose-jwt`
   - Không sử dụng `io.jsonwebtoken (jjwt)`

---

## 🛠 Công nghệ sử dụng

- Java 17
- Spring Boot 3 – Spring Security 6
- Spring Data JPA
- SQL Server
- Thymeleaf + jQuery (AJAX)
- Nimbus JOSE + JWT
